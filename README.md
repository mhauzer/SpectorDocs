## Way of Work

1. We use GitFlow
2. A PR that has not been accepted in 24 hours can be merged without an approval with exception of weekends and holidays.

   *If you create a PR during a weekend, you must wait at least till Tuesday before you can apply the rule.*

3. We write code in accordance to [PEP 8 – Style Guide for Python Code](https://peps.python.org/pep-0008/)
