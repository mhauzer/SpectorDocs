# Software Development Onboarding Process

1. We recommend Visual Studio Code as the primary development environment for software development.

## VS Code

1. Install the [Visual Studio Code](https://code.visualstudio.com/) editor if it is not already installed.
2. Install the recommended extensions for Python development, such as:
   - Python
   - Pylance
   - GitHub Repositories
   - Markdown All in One
   - markdownlint
3. Set the `Prune when fetching` option to `true`.
