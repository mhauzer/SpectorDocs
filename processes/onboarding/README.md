## Tools

### GitHub

#### Your GitHub Account

You need a [GitHub](https://github.com/) account to access the Spector Team's documents, code repositories, and projects.

[Create it](https://github.com/signup) if you don't have one. You can use your private or Capgemini email.

Share your GitHub account name with Michał Hauzer.

#### Learn to use GitHub Projects

We use GitHub Projects to manage our work. We create User Stories and tasks there, and we track their status (todo, in progress, done).

You can learn more about GitHub Projects from the [official documentation](https://docs.github.com/en/issues/planning-and-tracking-with-projects/learning-about-projects/about-projects).

### Markdown

We often create text content using [Markdown](https://en.wikipedia.org/wiki/Markdown) markup language.

Texts published on GitHub (as this onboarding document) use [GitHub's own Markdown flavour](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax).

You can use [Mermaid](https://mermaid.ai/open-source/intro/) for adding diagrams and flowcharts to your Markdown content.

Useful tool for emojis: [GitHub Emoji picker](https://github-emoji-picker.vercel.app/)

## Your Onboarding Checklist

```markdown
- [ ] Have you shared your GitHub account name with us?
- [ ] Do you have access to the Spector channel in FS CCA Python CoE team on MS Teams?
- [ ] Do you see the weekly meeting on Thursday at 2:00PM CET in your calendar?
- [ ] Do you know what GitHub repositories you need and do you have access to those repos?
- [ ] Do you know how to use Markdown?
```
